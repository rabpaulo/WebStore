# Capturas da aplicação

Capturas reais da aplicação, com PostgreSQL e serviços Docker em execução, sem credenciais ou tokens visíveis:

- `dashboard-desktop.jpg`: visão geral com indicadores.
- `products-desktop.jpg`: catálogo com variantes e disponibilidade.
- `inventory-desktop.jpg`: saldo de cada SKU.
- `order-detail.jpg`: itens, total e estado do pedido cancelado.
- `order-movements.jpg`: saída de venda e entrada de cancelamento do mesmo pedido.
- `dashboard-mobile.jpg`: menu recolhido e indicadores responsivos na área visível.

As imagens são versionadas para permitir a apresentação do portfólio sem iniciar o ambiente. Para novas capturas, utilize dados fictícios e revise o conteúdo antes de adicioná-las.
